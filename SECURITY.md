# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub's **Report a vulnerability** button on the repository's **Security** tab. Include the steps to reproduce it, the version or commit you tested and the impact you expect. You will get a reply when the report has been read; a fix and an advisory follow once the problem is confirmed.

## Supported versions

Only the latest `main` gets security fixes. There are no maintained release branches.
